# RadioMCU
Playing FM transmitter on various Microcontrollers without using any external hardware

Main inspiration (or you can say the copy) [Here](https://github.com/kaduhi/pico-fractional-pll)  


ALERT !!!

Do not use near public place , don't attach long wires in the GPIO 21 , it will act as an antenna and transmit long distances ,

which could easily be illegal in your country ! do it for experimental purposes 



I found the repo the don't own any , i just recompiled in my pico and tuned it to 90mhz ,it worked so , the .uf2 file shared is pre built from my system

 

Easy Instructions !!


Just press Boot pin on your Raspberry Pi Pico then plug it to your computer via usb cable

You will see a new drive

now either copy/paste or drag and drop this downloaded .uf2 file 


cheers ! now tune to it 90Mhz
